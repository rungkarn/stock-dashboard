## 1. วิธีอ่าน dashboard

หน้าเว็บอ่านจากบนลงล่าง จากภาพรวมของทั้งพอร์ตไปจนถึงรายละเอียดของหุ้นแต่ละตัว

### 1.1 หัวหน้า

แสดงวันที่ของราคาปิดล่าสุด จำนวนหุ้น และเวลาที่อัปเดต ถ้ามีหุ้นที่ Yahoo ไม่มีข้อมูล ชื่อจะขึ้นต่อท้ายว่า **"ไม่มีข้อมูล: …"**
ปุ่ม ◐ ที่มุมขวาบนใช้สลับโหมดสว่าง/มืด (เบราว์เซอร์จะจำค่าที่เลือกไว้)

### 1.2 ภาพรวมแนวโน้ม (แถบสี)

แถบแนวนอนแบ่งหุ้นทั้งพอร์ตออกเป็น 5 กลุ่มตาม [คะแนนแนวโน้ม](#21-คะแนนแนวโน้ม-06)

| สี | กลุ่ม | คะแนน |
|---|---|---|
| 🟩 เขียวเข้ม | ขาขึ้นแรง | 5–6 |
| 🟢 เขียวอ่อน | ขาขึ้น | 4 |
| ⬜ เทา | ทรงตัว | 2–3 |
| 🟥 แดงอ่อน | ขาลง | 1 |
| 🔴 แดงเข้ม | ขาลงแรง | 0 |

**คลิกที่ช่วงสีไหน ตารางด้านล่างจะกรองเหลือเฉพาะกลุ่มนั้น** (คลิกซ้ำเพื่อยกเลิก)
ถ้าส่วนเขียวกว้างขึ้นทุกสัปดาห์ แปลว่าพอร์ตโดยรวมกำลังแข็งแรงขึ้น

### 1.3 การ์ดตัวเลข

| การ์ด | ความหมาย |
|---|---|
| **เหนือ MA50** | % ของหุ้นที่ราคาอยู่เหนือเส้นเฉลี่ย 50 วัน (ภาพระยะกลาง) |
| **เหนือ MA200** | % ของหุ้นที่ราคาอยู่เหนือเส้นเฉลี่ย 200 วัน (ภาพระยะยาว) |
| **ชนะตลาด 3M** | จำนวนหุ้นที่ผลตอบแทน 3 เดือนสูงกว่า TDEX |
| **ค่ามัธยฐาน 1M** | ผลตอบแทน 1 เดือนของหุ้นที่อยู่ตรงกลางพอร์ต (ไม่ถูกตัวที่วิ่งแรงผิดปกติดึงค่า) |
| **New high / low 52W** | จำนวนหุ้นที่ทำจุดสูงสุดใหม่ (เขียว) / ต่ำสุดใหม่ (แดง) ในรอบปี |
| **ตลาด TDEX (SET50)** | ราคา TDEX, % เปลี่ยนวันนี้ และแนวโน้มของตลาด ใช้ดูว่าหุ้นเราขึ้นหรือลงไปพร้อมตลาดหรือไม่ |

### 1.4 สัญญาณล่าสุด

รวมหุ้นที่มีเหตุการณ์ทางเทคนิคเกิดขึ้น ตัวเลขเล็กข้างชื่อคือ % เปลี่ยนวันล่าสุด (ส่วนกลุ่ม Volume จะแสดงเป็นจำนวนเท่าของค่าเฉลี่ย) **คลิกชื่อหุ้นเพื่อเปิดกราฟ**

| สัญญาณ | เงื่อนไข | ใช้ดูอะไร |
|---|---|---|
| ▲ จุดสูงสุดใหม่ 52 สัปดาห์ | ราคาปิด ≥ ราคาปิดสูงสุดในรอบ 1 ปี | แรงซื้อ/โมเมนตัมดี |
| ✕ Golden cross | MA50 ตัดขึ้นเหนือ MA200 ภายใน 10 วันทำการ | แนวโน้มระยะยาวเริ่มกลับเป็นขาขึ้น |
| ↗ ราคาตัดขึ้นเหนือ MA50 | เกิดภายใน 3 วันทำการ | เริ่มฟื้นในระยะกลาง |
| ▮ Volume ≥ 2 เท่า | ปริมาณวันล่าสุด ≥ 2× ค่าเฉลี่ย 20 วันก่อนหน้า | มีเงินไหลเข้า/ออกผิดปกติ ต้องดูคู่กับทิศของราคา |
| ↘ ราคาหลุด MA50 | เกิดภายใน 3 วันทำการ | เริ่มอ่อนแรงในระยะกลาง |
| ✕ Death cross | MA50 ตัดลงใต้ MA200 ภายใน 10 วันทำการ | แนวโน้มระยะยาวเปลี่ยนเป็นขาลง |
| ▼ จุดต่ำสุดใหม่ 52 สัปดาห์ | ราคาปิด ≤ ราคาปิดต่ำสุดในรอบ 1 ปี | ยังไม่หยุดลง ควรทบทวนเหตุผลที่ถือ |

> สัญญาณจะกรองตามตัวกรองในตาราง (ค้นหา / แนวโน้ม / ที่ถือ–Watchlist) ด้วย

### 1.5 แถบเครื่องมือ

- **ค้นหาหุ้น…** พิมพ์ชื่อย่อหรือชื่อบริษัท (ภาษาอังกฤษ)
- **ทุกแนวโน้ม / ขาขึ้นแรง / …** กรองตามกลุ่มแนวโน้ม
- **ทั้งหมด / ที่ถือ / Watchlist** กรองตามกลุ่มหุ้น
- **ตาราง / Heatmap** สลับมุมมอง
- **ช่วง** (เฉพาะโหมด Heatmap) เลือกว่าจะระบายสีตามผลตอบแทนช่วงไหน

### 1.6 ตาราง

คลิกหัวคอลัมน์เพื่อเรียงลำดับ (คลิกซ้ำเพื่อกลับทิศ) ค่าเริ่มต้นเรียงตามคะแนนแนวโน้มจากมากไปน้อย **คลิกแถวเพื่อเปิดกราฟ**

| คอลัมน์ | ความหมาย |
|---|---|
| **หุ้น** | ชื่อย่อ ตัวที่มีป้าย `watch` คือหุ้นใน watchlist ที่ยังไม่ได้ถือ |
| **3 เดือน** | กราฟเส้นเล็กของราคาปิด 63 วัน จุดท้ายเป็นสีเขียวถ้าราคาสูงกว่าเมื่อ 3 เดือนก่อน และแดงถ้าต่ำกว่า |
| **ราคา / 1D** | ราคาปิดล่าสุด และ % เปลี่ยนจากวันก่อน |
| **1W 1M 3M 1Y** | ผลตอบแทนแต่ละช่วง ช่องยิ่งเขียวเข้มยิ่งขึ้นมาก ยิ่งแดงเข้มยิ่งลงมาก |
| **แนวโน้ม** | แท่งเล็ก 6 ช่อง คือคะแนน 0–6 (จำนวนช่องที่ระบายสี = จำนวนเงื่อนไขที่ผ่าน) ตามด้วยชื่อกลุ่ม |
| **vs MA200** | ราคาอยู่สูง (+) หรือต่ำ (−) กว่าเส้น MA200 กี่ % |
| **ช่วง 52 สัปดาห์** | จุดบนเส้นคือตำแหน่งราคาปัจจุบัน ซ้ายสุดคือต่ำสุดของปี ขวาสุดคือสูงสุดของปี (เอาเมาส์ชี้เพื่อดูตัวเลข) |
| **Vol / เฉลี่ย** | ปริมาณวันล่าสุด ÷ ค่าเฉลี่ย 20 วัน ถ้า ≥ 2× จะเป็นตัวหนา |
| **RSI** | RSI 14 วัน ค่า ≥ 70 (ซื้อมาก/ร้อนแรง) หรือ ≤ 30 (ขายมากเกินไป) จะแสดงเป็นสีเข้ม |
| **เทียบตลาด 3M** | ผลตอบแทน 3 เดือน − ผลตอบแทน TDEX ค่าบวกแปลว่าชนะตลาด |

### 1.7 Heatmap

แต่ละกล่องคือหุ้นหนึ่งตัว เรียงจากผลตอบแทนมากไปน้อย สีบอกขนาดของการขึ้น/ลงในช่วงที่เลือก
ใช้ดูภาพรวมทั้งพอร์ตได้ในหน้าเดียว เช่นเลือก "1 เดือน" แล้วดูว่าตัวไหนนำ ตัวไหนรั้งท้าย หรือเลือก "vs MA200" เพื่อดูว่าตัวไหนอยู่เหนือหรือต่ำกว่าเส้นยาว

| ช่วง | สีเข้มสุดเมื่อ |
|---|---|
| 1 วัน | ±5% |
| 1 สัปดาห์ | ±8% |
| 1 เดือน | ±15% |
| 3 เดือน | ±25% |
| 6 เดือน | ±35% |
| YTD | ±40% |
| 1 ปี | ±50% |
| vs MA200 | ±25% |

### 1.8 หน้ากราฟรายตัว

เปิดได้จากการคลิกแถวในตาราง กล่องใน Heatmap หรือชิปในส่วนสัญญาณ
ปิดด้วยปุ่ม ✕, คลิกพื้นที่มืดด้านนอก หรือกด `Esc`

- **กราฟแท่งเทียน** แท่งเขียวคือวันที่ปิดสูงกว่าราคาเปิด แท่งแดงคือปิดต่ำกว่า
- **เส้นเฉลี่ย** 🔵 MA20 (ระยะสั้น), 🟠 MA50 (ระยะกลาง), 🟣 MA200 (ระยะยาว)
- **แท่ง Volume** ด้านล่าง สีเขียวหรือแดงตามว่าราคาปิดสูงหรือต่ำกว่าวันก่อน
- **3M / 6M / 1Y / ทั้งหมด** เปลี่ยนช่วงเวลาที่แสดง (ข้อมูลเก็บไว้สูงสุด ~3 ปี) และใช้เมาส์ลาก/ล้อเลื่อนซูมได้
- **แถบตัวเลขเหนือกราฟ** เลื่อนเมาส์บนกราฟเพื่อดู O/H/L/C, % เปลี่ยน, Vol และค่า MA ของวันนั้น
- **การ์ดสถิติด้านล่าง** ผลตอบแทนทุกช่วง ค่า MA ความชันของ MA50 ช่วง 52 สัปดาห์ RSI ปริมาณ และมูลค่าซื้อขายเฉลี่ย 20 วัน (บอกสภาพคล่อง)

**แชร์ลิงก์ไปหุ้นตัวเดียวได้** โดยเติม `#ชื่อหุ้น` ท้าย URL เช่น
`https://rungkarn.github.io/stock-dashboard/#WHA`

### 1.9 ตัวอย่างการใช้งาน

| อยากรู้ | ทำแบบนี้ |
|---|---|
| ตัวไหนแข็งแรงที่สุด | ตารางเรียงตาม "แนวโน้ม" (ค่าเริ่มต้น) แล้วดูแถวบนสุด |
| ตัวไหนกำลังพัง | คลิกช่วง "ขาลงแรง" ในแถบภาพรวม หรือดูกลุ่ม ▼ จุดต่ำสุดใหม่ / ✕ Death cross |
| ตัวไหนเริ่มกลับตัว | ดูกลุ่ม ↗ ราคาตัดขึ้นเหนือ MA50 และ ✕ Golden cross แล้วเปิดกราฟดูว่า Volume หนุนหรือไม่ |
| ตัวไหนมีข่าว/เงินเข้า | กลุ่ม ▮ Volume ≥ 2 เท่า หรือเรียงตาราง "Vol / เฉลี่ย" |
| พอร์ตชนะตลาดไหม | การ์ด "ชนะตลาด 3M" หรือเรียงตาราง "เทียบตลาด 3M" |
| เดือนนี้ภาพรวมเป็นยังไง | Heatmap → ช่วง "1 เดือน" |

## 2. ตัวชี้วัดคำนวณอย่างไร

ทุกค่าคำนวณจาก **ราคาปิด** ใน `scripts/fetch_prices.py` → `data/summary.json`
(ราคาปรับการแตก/รวมหุ้นแล้ว แต่ไม่ได้ปรับเงินปันผล) "n วัน" หมายถึงวันทำการ

### 2.1 คะแนนแนวโน้ม (0–6)

ได้ 1 คะแนนต่อเงื่อนไขที่ผ่าน:

1. ราคา > MA20
2. ราคา > MA50
3. ราคา > MA200
4. MA20 > MA50 (เส้นสั้นอยู่เหนือเส้นกลาง)
5. MA50 > MA200 (เส้นกลางอยู่เหนือเส้นยาว)
6. MA50 วันนี้ > MA50 เมื่อ 10 วันก่อน (เส้นกลางกำลังชันขึ้น)

หุ้นที่มีประวัติไม่ถึง 200 วัน (เพิ่ง IPO) จะไม่ได้คะแนนในเงื่อนไขที่ต้องใช้ MA200

### 2.2 ค่าอื่น ๆ

| ค่า | สูตร |
|---|---|
| 1D / 1W / 1M / 3M / 6M / 1Y | ราคาปิดวันนี้เทียบกับ 1 / 5 / 21 / 63 / 126 / 252 วันก่อน |
| YTD | เทียบกับราคาปิดวันสุดท้ายของปีก่อน |
| สูงสุด/ต่ำสุด 52 สัปดาห์ | High/Low ของ 252 วันล่าสุด (สัญญาณ new high/low ใช้ราคาปิด และต้องมีข้อมูล ≥ 120 วัน) |
| RSI | RSI 14 วันแบบ Wilder |
| Vol / เฉลี่ย | ปริมาณวันล่าสุด ÷ ค่าเฉลี่ย 20 วันก่อนหน้า (ไม่นับวันล่าสุด) |
| มูลค่าซื้อขายเฉลี่ย | เฉลี่ยของ (ราคาปิด × ปริมาณ) 20 วัน |
| เทียบตลาด 3M | ผลตอบแทน 3M ของหุ้น − ผลตอบแทน 3M ของ TDEX |

ถ้าจะปรับเกณฑ์ (เช่นจำนวนวันของสัญญาณ หรือเกณฑ์ Volume 2×) ให้แก้ฟังก์ชัน `metrics()` ใน `scripts/fetch_prices.py`
แล้วรัน `python scripts/fetch_prices.py --no-fetch` เพื่อคำนวณใหม่โดยไม่ต้องดึงข้อมูลซ้ำ

## 3. การอัปเดตอัตโนมัติ

ไฟล์ `.github/workflows/update.yml` ทำงานแบบนี้:

```
จ.–ศ. 11:15 UTC (18:15 น. ไทย)
  → ดึงราคา 1 เดือนล่าสุดของทุกหุ้นจาก Yahoo แล้วรวมเข้ากับประวัติเดิม
  → คำนวณ data/summary.json ใหม่
  → ถ้ามีแท่งราคาใหม่ จะ commit "data: prices YYYY-MM-DD"
  → deploy หน้าเว็บขึ้น GitHub Pages
```

- **วันหยุดตลาด** ไม่มีแท่งใหม่ก็จะไม่ commit แต่หน้าเว็บยังถูก deploy ตามปกติ
- **เวลาอาจคลาด** GitHub อาจเริ่ม cron ช้ากว่ากำหนด 10–60 นาทีในช่วงที่มีคนใช้เยอะ
- **ถ้าไม่มี commit ใน repo นาน 60 วัน** GitHub จะปิด cron ให้อัตโนมัติ (ปกติจะมี commit ข้อมูลทุกวันทำการอยู่แล้ว) ถ้าโดนปิด ให้ไปที่ Actions แล้วกด **Enable workflow**
- **push โค้ดขึ้น `main`** (ไฟล์ที่ไม่ใช่ `data/`) จะ deploy หน้าเว็บใหม่ทันทีโดยไม่ดึงราคา

### สั่งรันเอง

GitHub → แท็บ **Actions** → **Update prices & deploy** → **Run workflow**
ติ๊ก **full** ถ้าต้องการดึงย้อนหลัง 2 ปีใหม่ทั้งหมด (เช่นเมื่อสงสัยว่าข้อมูลเพี้ยน)

หรือสั่งผ่าน command line:

```bash
gh workflow run update.yml -R rungkarn/stock-dashboard
gh workflow run update.yml -R rungkarn/stock-dashboard -f full=true
```

ดูผลการรันได้ที่แท็บ Actions หรือใช้คำสั่ง `gh run list -R rungkarn/stock-dashboard`

## 4. เมื่อพอร์ตเปลี่ยน (เพิ่ม/ลบหุ้น)

รายชื่อหุ้นอยู่ใน `symbols.json`:

```json
{
 "holdings": ["ABM", "ACC", "..."],
 "watchlist": ["DELTA"]
}
```

### วิธี A: sync จาก repo private (แนะนำ)

หลังจาก refresh พอร์ตในโปรแกรม suite แล้ว (Portfolio → Fetch และ Dividends → Update ซึ่งจะอัปเดต `data/portfolio_dividend.json` และ `data/watchlist.json`) ให้รันคำสั่งต่อไปนี้ในโฟลเดอร์ `stock-dashboard`:

```bash
python scripts/sync_symbols.py "D:/oneDrive/OneDrive - NSTDA/Projects/stock"
python scripts/fetch_prices.py
git add -A
git commit -m "update symbols"
git push
```

สคริปต์จะอ่าน**แค่ชื่อหุ้น** (หุ้น NVDR `-R` จะรวมเข้ากับหุ้นแม่) แล้วพิมพ์บอกว่ามีตัวไหนเพิ่ม (`+`) หรือหายไป (`-`)
หุ้นที่อยู่ทั้งในพอร์ตและ watchlist จะนับเป็น "ที่ถือ"

### วิธี B: แก้ไฟล์เอง

แก้ `symbols.json` บนหน้าเว็บ GitHub (ปุ่มดินสอ ✏️) → Commit → จากนั้นไปที่ Actions → **Run workflow**
หุ้นตัวใหม่จะถูกดึงย้อนหลัง 2 ปีให้อัตโนมัติ

> ไฟล์ราคาของหุ้นที่ลบออกจะยังค้างอยู่ใน `data/prices/` ซึ่งไม่มีผลกับหน้าเว็บ ถ้าอยากลบให้ใช้ `git rm data/prices/<SYM>.json`

## 5. รันและดูในเครื่อง

ต้องมี Python 3.9 ขึ้นไป และแพ็กเกจ `requests`

```bash
pip install requests
python scripts/fetch_prices.py              # ดึงเพิ่ม 1 เดือนล่าสุด แล้วคำนวณใหม่
python scripts/fetch_prices.py --full       # ดึงย้อนหลัง 2 ปีใหม่ทุกตัว
python scripts/fetch_prices.py WHA DELTA    # ดึงเฉพาะบางตัว
python scripts/fetch_prices.py --no-fetch   # ไม่ดึง แค่คำนวณ summary.json ใหม่
python -m http.server 8765                  # แล้วเปิด http://localhost:8765
```

ต้องเปิดผ่าน `http.server` เพราะถ้าดับเบิลคลิก `index.html` ตรง ๆ เบราว์เซอร์จะไม่ยอมโหลดไฟล์ JSON

## 6. โครงสร้างไฟล์

```
stock-dashboard/
├── index.html                  หน้า dashboard
├── assets/
│   ├── app.js                  ตาราง, heatmap, สัญญาณ, กราฟ (TradingView Lightweight Charts 4.2)
│   └── style.css               สีและ layout (สว่าง/มืด, มือถือ)
├── symbols.json                รายชื่อหุ้น (holdings + watchlist)
├── data/
│   ├── summary.json            ตัวชี้วัดของทุกหุ้น (ตาราง/heatmap/สัญญาณอ่านจากไฟล์นี้)
│   └── prices/<SYM>.json       OHLCV รายวัน ~3 ปี (หน้ากราฟอ่านจากไฟล์นี้)
├── scripts/
│   ├── fetch_prices.py         ดึงราคา + คำนวณ summary
│   └── sync_symbols.py         สร้าง symbols.json จาก repo private
└── .github/workflows/
    └── update.yml              cron จ.–ศ. + deploy Pages
```

รูปแบบของ `data/prices/<SYM>.json`:

```json
{"symbol": "WHA", "name": "WHA Corporation ...", "currency": "THB",
 "bars": [["2026-10-15", 4.96, 5.05, 4.92, 5.0, 127962300], ...]}
```

แต่ละแท่งคือ `[วันที่, open, high, low, close, volume]`
ชื่อไฟล์ที่ชนกับชื่อสงวนของ Windows (เช่น `COM7`) จะเติม `_` ต่อท้าย และสัญลักษณ์อย่าง `^` จะถูกแทนด้วย `_`

## 7. แก้ปัญหา

| อาการ | สาเหตุ / วิธีแก้ |
|---|---|
| หัวหน้าเขียน "ไม่มีข้อมูล: …" | Yahoo ไม่มีหุ้นตัวนั้น เช่น warrant (DCON272A) หรือหุ้นที่ถูก SP ซึ่งแก้จากฝั่งนี้ไม่ได้ ถ้าขายหมดแล้วให้ลบออกจาก `symbols.json` |
| วันที่ราคาปิดไม่ขยับ | วันหยุดตลาด หรือ Yahoo ยังไม่ได้ปล่อยแท่งของวันนั้น รอบถัดไปจะเติมให้เอง ตรวจได้จากแท็บ Actions |
| Workflow ขึ้นสีแดง | เปิด log ของขั้น "Fetch prices" ถ้าดึงไม่ได้เกินครึ่ง สคริปต์จะ fail ทั้งรอบ (Yahoo ล่มหรือ rate limit) ให้กด Run workflow ใหม่ภายหลัง |
| cron ไม่รันแล้ว | repo ไม่มีความเคลื่อนไหว 60 วัน ให้ไปที่ Actions แล้วกด Enable workflow |
| หน้าเว็บไม่อัปเดตหลัง push | รอ deploy ประมาณ 1–2 นาที แล้วกด `Ctrl+F5` |
| ราคาดูกระโดดผิดปกติ | อาจเกิดจาก XR/แตกพาร์ ให้ Run workflow แบบติ๊ก **full** เพื่อดึงราคาที่ปรับแล้วใหม่ทั้งหมด |

### ทำไมไม่ใช้ set.or.th

set.or.th อยู่หลัง Incapsula ซึ่งบล็อก IP ของ data center นอกประเทศไทย (GitHub Actions, Claude Code cloud) จึงใช้ Yahoo Finance แทน
Yahoo ไม่มีประวัติย้อนหลังของดัชนี SET/SET50 จึงใช้ **TDEX** (ThaiDEX SET50 ETF) เป็นตัวเทียบตลาดแทน
